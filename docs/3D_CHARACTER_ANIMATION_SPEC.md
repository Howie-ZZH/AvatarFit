# FitGame Rex 3D 角色 MVP 动画规格

本文档面向 3D 动画师，用于制作 FitGame 主角 `Rex` 的首批 MVP 动画。动画需服务 Unity 移动端首屏、训练动作展示、结果反馈和分享截图，视觉方向、模型结构和材质约束以以下文档为准：

```text
docs/3D_CHARACTER_DESIGN_BRIEF.md
docs/3D_CHARACTER_ART_TASKS.md
docs/3D_CHARACTER_MODELING_HANDOFF.md
```

## 1. 通用动画要求

- 角色定位：年轻、健康、自信的半写实动漫 / 3D 游戏运动主角，不做 Q 版、机器人或夸张英雄化表演。
- 骨骼要求：必须可重定向到 Unity Humanoid；动画 FBX 与 `rex_base_humanoid.fbx` 保持骨骼命名、比例、朝向和根节点一致。
- 姿态基准：源文件可使用 T-Pose 或 A-Pose，当前推荐 A-Pose；导出动画前需确认 Avatar 校准无肩部扭曲。
- Root Motion：MVP 默认全部 In Place，Unity 侧默认关闭 Root Motion；除非工程另行确认，不让角色产生实际位移。
- 小屏优先：所有关键姿势在手机竖屏全身显示时仍需清楚，避免只靠手指、手腕、眼神等微动作表达状态。
- 风格节奏：动作可以有游戏感和能量感，但不做杂技、舞蹈化过强或夸张卡通弹性。
- 服装约束：重点检查连帽上衣下摆、帽子、短裤裤脚、压缩裤膝髋区域、运动鞋鞋口和双腕腕带。
- 命名要求：Unity Clip 名与动画名一致，动画 FBX 文件名使用 `rex_` 前缀。
- 帧率建议：源动画按 30 fps 或 60 fps 制作均可，交付需说明；Unity 中应能稳定循环或播放，无明显顿挫。

## 3. 单项动画规格

### 3.1 idle_default

用途：

- 首屏默认待机，用于角色长期展示。
- 表达 Rex 健康、放松、可亲近，但仍有训练感。
- 可作为多数非训练状态的基础循环。

时长建议：

- 3.0-4.0 秒。
- 循环动画，首尾姿势必须自然衔接，不允许明显跳帧。

关键姿势：

- 站姿为自然双脚分开，脚距略小于肩宽，膝盖微松。
- 躯干保持直立，胸口不过度外挺。
- 呼吸带动胸腔和肩部轻微起伏，重心可在左右脚之间小幅转移。
- 手臂自然下垂，手腕轻微放松，双腕腕带保持可见。
- 头部可有非常轻微的抬低或左右观察，但不要频繁转头。

手机小屏可读性：

- 全身缩小后仍能读出稳定站姿和轻微呼吸。
- 黑灰服装层次不能因动作幅度过小而完全静止，建议用肩胸起伏和重心变化制造生命感。
- 青绿色胸前标记、腿部线条和鞋型不要被手臂遮挡。

穿模风险：

- 上衣下摆在髋部重心转移时不要穿入短裤。
- 腕带随手腕轻微旋转时不要穿入前臂。
- 头发和帽子后缘在头部轻微转动时不要互相穿插。

Unity Clip 命名：

```text
Clip: idle_default
FBX: rex_idle_default.fbx
```

### 3.2 idle_confident

用途：

- 用于状态更好、训练完成后回到首屏、角色自信状态展示。
- 比 `idle_default` 更挺拔、更有主角感，但仍可长时间循环。

时长建议：

- 3.0-4.0 秒。
- 循环动画，结尾回到开头时姿态差异要小。

关键姿势：

- 双脚稳定分开，站姿比默认待机更挺拔。
- 胸腔略打开，肩膀自然向后，头部微抬。
- 一只手可轻搭腰侧或靠近髋部，另一只手自然放松；不要挡住胸前青绿色标记。
- 可加入轻微点头、肩部放松或握拳再放松的小动作，表达自信。
- 表情建议中性微笑或轻自信，不做夸张大笑。

手机小屏可读性：

- 剪影需明显区别于 `idle_default`：胸肩更开、头更高、手臂姿态更明确。
- 手臂不要交叉挡住脸、胸前标记和上衣拉链结构。
- 正面和 3/4 视角都应读出“准备好了”的感觉。

穿模风险：

- 手搭腰侧时，手指、腕带和上衣侧边容易穿模，需要留出间距。
- 肘部靠近身体时检查袖口、腋下和上衣侧缝。
- 胸肩打开时帽子不要被肩颈挤压变形。

Unity Clip 命名：

```text
Clip: idle_confident
FBX: rex_idle_confident.fbx
```

### 3.3 intro_hero

用途：

- App 首屏进入、角色首次展示或从加载状态切入时播放。
- 结尾需要能自然衔接 `idle_default` 或 `idle_confident`。

时长建议：

- 1.8-2.4 秒。
- 非循环动画。

关键姿势：

- 起始可从轻微低头、侧身 3/4 或准备站稳的姿态开始。
- 中段角色抬头、转正或转向镜头，胸肩打开。
- 末段双脚站稳，形成清晰主角站姿。
- 可加入一只手轻握拳、调整腕带或轻抬手臂的动作，强化运动主角感。
- 结尾姿势建议接近 `idle_confident` 的第一帧，便于 Unity 混合。

手机小屏可读性：

- 登场动作的轮廓变化要大于普通待机，但不要让角色离开首屏安全区域。
- 抬头、开肩和站稳这三个节点需要在竖屏全身构图中清楚。
- 不依赖快速手部细节表达，手部动作只作为辅助。

穿模风险：

- 转身或开肩时重点检查帽子、肩袖、上衣下摆。
- 调整腕带时检查手掌、手指、腕带和袖口。
- 躯干从侧向转正时，短裤和压缩裤髋部不要互相穿插。

Unity Clip 命名：

```text
Clip: intro_hero
FBX: rex_intro_hero.fbx
```

### 3.4 result_success

用途：

- 单次训练完成、打卡成功或任务完成后的积极反馈。
- 表达“完成得不错”，强度低于升级动画。

时长建议：

- 1.6-2.2 秒。
- 非循环动画，结尾建议可回到 `idle_confident`。

关键姿势：

- 起始为站立准备姿势。
- 中段可做轻快握拳、单臂上扬或小幅庆祝动作。
- 身体重心可轻微上提，但不建议大跳。
- 结尾站稳，胸肩打开，面部保持微笑或自信。
- 动作应积极、干净，不做夸张胜利舞。

手机小屏可读性：

- 庆祝手臂应有清晰剪影，建议一臂上扬或斜向外打开。
- 手臂不能遮挡脸部和胸前识别标记太久。
- 角色脚底应保持稳定，避免小屏上看起来像漂浮。

穿模风险：

- 单臂上扬时检查肩袖、腋下和帽子边缘。
- 握拳靠近胸口时检查手掌与上衣拉链、胸前标记。
- 重心上提或落下时检查鞋底接地和裤脚。

Unity Clip 命名：

```text
Clip: result_success
FBX: rex_result_success.fbx
```

### 3.5 result_level_up

用途：

- 角色升级、等级提升或重大训练成果反馈。
- 可与 Unity 侧光效、粒子或 UI 反馈配合，动作需要比 `result_success` 更明显。

时长建议：

- 2.2-3.0 秒。
- 非循环动画，结尾可回到 `idle_confident`。

关键姿势：

- 起始为站立或轻微蓄力姿势，膝盖微弯，双手靠近身体两侧。
- 中段身体上提，双臂向外或向上打开，形成清晰升级剪影。
- 可加入短暂停顿作为特效爆发点，胸口和腿部青绿色线条应露出。
- 末段收回到稳定自信站姿。
- 表演应有能量感，但不做翻身、旋转跳跃或过度夸张弹性。

手机小屏可读性：

- 需要有清晰的“蓄力-打开-站稳”三段式轮廓。
- 双臂打开时不要超出首屏裁切风险范围，头部和鞋子仍需在安全框内。
- 配合特效时，角色身体关键线条不能被手臂遮住。

穿模风险：

- 蓄力下蹲时检查短裤裤脚、髋部和上衣下摆。
- 双臂上举或外打开时检查肩袖、腋下、帽子与肩颈。
- 手腕旋转时检查腕带和袖口。

Unity Clip 命名：

```text
Clip: result_level_up
FBX: rex_result_level_up.fbx
```

### 3.6 workout_squat

用途：

- 深蹲训练动作，用于 App 内训练状态循环展示。
- 动作需要准确、健康，能让用户一眼看出是深蹲。

时长建议：

- 2.0-2.6 秒完成一次“站立-下蹲-站起”。
- 循环动画，首尾均为站立准备姿势。

关键姿势：

- 起始站立，双脚略宽于肩，脚尖微外展。
- 双臂可前伸保持平衡，或双手轻握拳放在胸前；推荐前伸以增强小屏可读性。
- 下蹲阶段髋部向后，膝盖弯曲，背部保持较直，不塌腰。
- 最低点大腿接近水平即可，不追求过深，避免穿模和变形风险。
- 上升阶段脚跟稳定，膝盖方向跟随脚尖，回到起始姿势。

手机小屏可读性：

- 侧面或 3/4 视角下应清楚看到髋部后坐和膝盖弯曲。
- 手臂前伸能形成清晰剪影，但不要遮挡脸部。
- 下蹲最低点和站立最高点差异要明显，避免看起来只是轻微点头。

穿模风险：

- 最高风险为短裤裤脚与大腿、上衣下摆与髋部、膝盖弯曲处压缩裤塌陷。
- 手臂前伸时检查肩袖、腋下、腕带。
- 鞋底需要保持接地，不要脚尖或脚跟穿入地面。

Unity Clip 命名：

```text
Clip: workout_squat
FBX: rex_workout_squat.fbx
```

### 3.7 workout_jumping_jack

用途：

- 开合跳训练动作，用于有氧训练循环展示。
- 需要节奏明确、剪影强、手机小屏一眼可读。

时长建议：

- 1.2-1.8 秒完成一次“合-开-合”。
- 循环动画，首尾回到双脚合拢或自然小开立姿势。

关键姿势：

- 起始双脚接近并拢，双臂自然在身体两侧。
- 打开姿势为双脚向外落地，双臂向侧上方打开，可接近头顶但不必双手相触。
- 回收姿势为双脚回到起始位置，双臂回落。
- 躯干保持稳定，不要大幅前后晃动。
- 动作应有轻微弹性，但角色整体保持 In Place。

手机小屏可读性：

- 开合两帧的身体宽度差异要非常明确。
- 手臂上举时要形成干净 V 字或弧线剪影。
- 不建议做过快频率，否则小屏和低帧率下容易看成抖动。

穿模风险：

- 双臂上举时检查肩袖、腋下、帽子和头发。
- 双脚外跳落地时检查短裤裤脚、大腿内侧、鞋底接地。
- 腕带在手臂快速摆动时不要穿入手腕或袖口。

Unity Clip 命名：

```text
Clip: workout_jumping_jack
FBX: rex_workout_jumping_jack.fbx
```

### 3.8 workout_plank

用途：

- 平板支撑训练动作，用于核心训练循环展示。
- 动作需要稳定、有力量感，体现身体控制。

时长建议：

- 3.0-4.0 秒。
- 循环动画，首尾姿势一致；循环内以呼吸和轻微稳定调整为主。

关键姿势：

- 角色以前臂或双手支撑均可，MVP 推荐前臂支撑，剪影稳定且穿模风险较低。
- 肩、髋、踝基本连成直线，腰部不塌，臀部不过高。
- 脚尖支撑地面，双腿自然分开。
- 头部看向地面前方，颈部与脊柱自然延伸。
- 循环中加入轻微呼吸、肩背微动和身体稳定细调。

手机小屏可读性：

- 建议 Unity 展示时使用 3/4 或侧向角度；动画本身需要侧面剪影清晰。
- 身体从肩到脚的直线必须明显，不能蜷成一团。
- 青绿色腿部能量线和鞋型应尽量露出，帮助小屏识别身体方向。

穿模风险：

- 帽子和头发在低头时可能碰到胸口或肩部，需要留出空间。
- 上衣下摆受重力方向变化影响，不能穿进短裤或腹部。
- 短裤裤脚、髋部、膝踝角度和鞋尖接地是重点检查区域。
- 前臂支撑时腕带不要穿入地面或前臂。

Unity Clip 命名：

```text
Clip: workout_plank
FBX: rex_workout_plank.fbx
```

### 3.9 workout_stretch

用途：

- 拉伸训练动作，用于训练前后舒展或恢复状态。
- 需要表达放松、延展和健康运动，不做极限柔术。

时长建议：

- 3.0-4.5 秒。
- 循环动画，首尾回到同一拉伸侧或中性过渡姿势。

关键姿势：

- 推荐做站姿侧向拉伸或站姿腿后侧拉伸，MVP 优先站姿侧向拉伸，镜头可读性更好。
- 起始双脚稳定分开，一手扶髋或自然下垂，另一手从侧上方延展。
- 中段身体向一侧轻弯，侧腰拉开，头部跟随方向自然转动。
- 保持 1 个清晰延展停顿，再缓慢回到起始。
- 动作幅度要舒展但不过度压缩髋部和肩部。

手机小屏可读性：

- 延展手臂和侧弯躯干要形成明确弧线。
- 手臂不要挡脸，胸前青绿色标记尽量保留可见。
- 站姿双脚要稳定，不能因为上身侧弯而看起来失衡。

穿模风险：

- 手臂越过头顶时检查肩袖、帽子、头发和脸部遮挡。
- 侧弯时检查上衣下摆与短裤、髋部与压缩裤。
- 扶髋手容易穿入上衣侧边或腕带，需要留出可见间距。

Unity Clip 命名：

```text
Clip: workout_stretch
FBX: rex_workout_stretch.fbx
```

### 3.10 pose_share_01

用途：

- 用于训练结果分享截图、角色展示卡片或社交分享封面。
- 目标是定格时清晰、帅气、可识别，优先服务截图，不追求复杂动态。

时长建议：

- 1.0-1.5 秒进入定格姿势。
- 非循环动画；末尾姿势需至少可在 Unity 中保持为截图姿势。

关键姿势：

- 推荐 3/4 正面站姿，身体略转向镜头，头部看向镜头。
- 一只手可比出轻握拳、拇指朝上或自然自信手势；另一只手放松或轻搭腰侧。
- 胸肩打开，胸前青绿色标记、上衣拉链、腿部能量线和鞋型都要露出。
- 表情为轻自信微笑，避免大张口或夸张表情。
- 末尾定格姿势必须稳定，脚底接地，角色重心可信。

手机小屏可读性：

- 分享图可能被裁切或叠加 UI，姿势必须在全身和半身裁切下都可读。
- 手臂不能遮挡脸、胸前标记或大面积身体轮廓。
- 头发轮廓、脸部朝向、腕带和鞋底浅色细节应作为识别点保留。

穿模风险：

- 手势靠近身体时检查手指、腕带、上衣和胸前标记。
- 手搭腰侧时检查手掌与短裤腰线、上衣下摆。
- 3/4 转体时检查短裤、压缩裤髋部和鞋子朝向。

Unity Clip 命名：

```text
Clip: pose_share_01
FBX: rex_pose_share_01.fbx
```

## 4. Unity 交付与检查清单

动画师交付前需逐项自检：

- 10 个 Clip 均可在 Unity Animator 中播放。
- `idle_default`、`idle_confident`、`workout_squat`、`workout_jumping_jack`、`workout_plank`、`workout_stretch` 循环无明显跳帧。
- `intro_hero`、`result_success`、`result_level_up`、`pose_share_01` 结尾可自然停住或过渡到待机。
- 训练动作均为 In Place，Root Motion 默认关闭后角色不漂移。
- 手机竖屏全身展示时，动作意图清楚，关键姿势不依赖细小手部动作。
