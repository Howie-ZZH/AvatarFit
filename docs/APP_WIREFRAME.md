# App 页面需求 v0.1

## 1. 目标

App 端负责承载用户完整使用流程：

```text
首日建角
  -> 输入身体数据
  -> 3 分钟测试训练
  -> 首次成长反馈
  -> 角色主页
  -> 日常训练、课程、AI 教练、换装、分享
```

首版按 Flutter 跨平台实现，同时支持 iOS 和 Android。

## 2. 信息架构

### 2.1 首次进入流程

## 4. 启动页

### 目标

第一眼传达“酷感 3D 游戏化健身”，避免看起来像普通健身工具。

### 页面内容

- 全屏 3D 角色登场动画或预渲染视频
- App 名称
- 登录 / 注册入口

### 关键要求

- 角色尽早出现
- 首屏有游戏感、力量感、未来训练感
- 不做长篇功能介绍
- 不使用普通健身 App 的静态宣传页风格

## 5. 登录 / 注册页

### MVP 支持

- 邮箱注册
- 邮箱登录

### 预留

- Apple 登录
- Google 登录
- 中国区手机号登录
- 微信登录

### 字段

```text
email
password
region
language
```

### 完成后

进入创建角色页。

## 6. 创建角色页

### 目标

让用户感觉是在创建游戏 Avatar，而不是填写健身档案。

### 页面内容

- 中央 3D 角色预览
- 基础类型：男性 / 女性 / 中性
- 风格类型：力量型 / 燃脂型 / 敏捷型 / 平衡型
- 基础服装预览
- 角色名称输入
- 下一步按钮

### 请求

```json
{
  "name": "Rex",
  "baseType": "male",
  "styleType": "balanced"
}
```

## 7. 身体数据页

### 目标

收集生成初始角色和训练计划所需数据。

### 必填

- 年龄
- 身高
- 体重
- 训练经验：新手 / 有基础 / 进阶
- 每周可训练天数

### 可选

- 体脂率
- 性别
- 围度，后续加入

### 文案原则

- 积极表达，不羞辱用户
- 强调数据用于生成训练计划和角色成长趋势
- 不用“胖、差、弱”等负面标签

## 8. 健身目标页

### 目标

确定训练计划和角色成长方向。

### 目标选项

- 减脂
- 增肌
- 塑形
- 提升体能
- 保持健康

### 完成后

调用后端创建或更新档案，并进入初始角色生成页。

## 9. 初始角色生成页

### 目标

让用户第一次看到“自己映射出来的角色”。

### 页面内容

- 3D 角色展示
- 初始等级 Lv.1
- 初始属性条或雷达图
- 角色状态一句话反馈
- 开始 3 分钟测试训练按钮

### 示例反馈

```text
你的角色目前处于初始训练状态。完成测试训练后，我们会为你调整第一周计划。
```

### Unity 指令

```json
{
  "type": "SET_AVATAR_STATE",
  "payload": {
    "level": 1,
    "energyState": "normal",
    "bodyType": "normal"
  }
}
```

## 10. 3 分钟测试训练页

### 目标

让用户马上体验“角色带我训练”。

### 首版动作

- 深蹲
- 开合跳
- 平板支撑
- 拉伸

### 页面内容

- 3D 角色动作示范
- 当前动作名称
- 当前动作说明
- 倒计时
- 组数 / 次数
- 休息倒计时
- 暂停按钮
- 跳过按钮
- 完成按钮

### 动作开始时 Unity 指令

```json
{
  "type": "START_EXERCISE",
  "payload": {
    "exerciseId": "squat_basic",
    "animationKey": "workout_squat",
    "durationSeconds": 45,
    "sets": 2,
    "reps": 12
  }
}
```

### 动作结束时 Unity 指令

```json
{
  "type": "END_EXERCISE",
  "payload": {
    "exerciseId": "squat_basic",
    "completed": true
  }
}
```

## 11. 首次成长反馈页

### 目标

让用户明确感受到训练后角色成长。

### 页面内容

- 角色成功 / 升级动画
- XP 增长
- 属性变化
- 解锁新手装备
- 分享按钮
- 进入主页按钮

### 后端返回后转发 Unity

```json
{
  "type": "WORKOUT_COMPLETE",
  "payload": {
    "xpGained": 80,
    "levelBefore": 1,
    "levelAfter": 2,
    "attributeDelta": {
      "strength": 2,
      "endurance": 1,
      "core": 1,
      "flexibility": 0,
      "fatBurn": 1,
      "recovery": 0
    }
  }
}
```

## 13. 训练 Tab

### 目标

让用户快速开始每日训练。

### 页面内容

- 今日训练计划
- 预计时长
- 动作列表
- 训练目标
- 开始训练按钮
- 训练历史入口

### 训练中页面

复用 3 分钟测试训练页结构。

### 训练完成

调用：

```text
POST /api/workouts/sessions/{sessionId}/complete
```

然后进入成长反馈页。

### 目标

### 页面内容

### 页面内容

- 今日建议
- 角色口吻反馈
- 推荐训练卡片

### MVP 能力

- 发送问题
- 后端返回建议
- 展示推荐训练

## 16. 我的 Tab

### 页面内容

- 个人资料
- 身体数据
- 成就
- 订单 / 订阅入口
- 语言 / 地区
- 隐私设置
- 退出登录

## 17. 换装页

### 目标

支撑皮肤商业化和角色表达。

### 页面内容

- 3D 角色预览
- 资产分类：服装、鞋子、配饰、材质、姿势、背景
- 已拥有 / 未拥有状态
- 稀有度标识
- 装备按钮
- 购买按钮，后续启用

### 装备流程

```text
用户点击装备
  -> POST /api/assets/{assetId}/equip
  -> 后端返回 unityEvent
  -> Flutter 转发 CHANGE_OUTFIT 给 Unity
```

## 18. 分享页

### 目标

形成传播，让角色成果变成可分享内容。

### 分享类型

- 今日训练完成卡
- 首次成长卡
- 本周成长对比
- 角色展示图

### MVP 流程

```text
Flutter -> Unity: SET_POSE
Flutter -> Unity: CAPTURE_SHARE_IMAGE
Unity -> Flutter: SHARE_IMAGE_CAPTURED
Flutter 合成海报或直接调用系统分享
```

## 19. Flutter 侧服务封装

建议封装：

```text
UnityAvatarService
- sendCommand(type, payload)
- setAvatarState(avatar)
- playAnimation(animationKey)
- startExercise(exercise)
- completeWorkout(growthResult)
- changeOutfit(equipment)
- captureShareImage(template)
```

页面不要直接拼 JSON。

## 20. 异常和降级

必须处理：

- Unity 未初始化
- 动画 key 不存在
- 资产 key 不存在
- 截图失败
- 通信超时
- App 切后台后 Unity 状态恢复

降级策略：

- Unity 失败时角色页显示占位图和重试按钮。
- 训练动作没有 3D 动画时显示第三方视频 / 动图。
- 训练完成接口成功后，即使 Unity 动画失败，也不能丢训练结果。

## 21. 首日体验验收

- 用户 5 分钟内完成首日流程
- 角色在启动后尽早出现
- 3 分钟测试训练有明确动作反馈
- 训练结束后能看到 XP 和属性成长
- 用户可以进入角色主页继续探索
