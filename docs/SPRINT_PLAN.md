# MVP 开发排期与任务看板 v0.1

## 1. 阶段目标

第一阶段目标是做出可演示 MVP：

```text
创建 3D 角色
  -> 完成一次训练
  -> 角色播放动作
  -> 获得 XP / 属性成长
  -> 播放成长反馈
  -> 换装
  -> 分享
```

## 2. 总体排期

| 阶段 | 时间 | 目标 |
|---|---|---|
| 产品与设计 | 第 1-2 周 | PRD、信息架构、角色风格、低保真 |
| 3D 验证 | 第 3-5 周 | Unity 角色、动作、嵌入验证 |
| MVP 开发 | 第 6-10 周 | 账号、角色、训练、后端、课程接入 |
| 商业化与分享 | 第 11-12 周 | 换装、分享、课程入口、AI 入口 |
| 测试与上线准备 | 第 13-14 周 | 真机测试、多语言、性能、合规 |

## 5. 后端 Sprint

### Sprint 1：账号、档案、角色基础

目标：用户能注册登录，创建身体档案和初始角色。

| 模块 | 任务 | 优先级 |
|---|---|---|
| auth | 注册、登录、JWT 鉴权 | P0 |
| user | 获取当前用户信息 | P0 |
| profile | 创建 / 更新身体档案 | P0 |
| avatar | 创建初始角色 | P0 |
| avatar | 获取角色状态和 6 大属性 | P0 |
| db | 建表：users、user_profiles、avatars、avatar_attributes | P0 |
| docs | Swagger / OpenAPI 文档 | P0 |

验收：

- 注册 -> 登录 -> 建档 -> 创建角色 -> 获取角色状态 能完整跑通。

### Sprint 2：课程、动作、训练完成、成长计算

目标：用户能拿到今日训练，完成训练后角色成长。

| 模块 | 任务 | 优先级 |
|---|---|---|
| course | 动作库表和课程表 | P0 |
| course | 第三方 API 适配 mock 版 | P0 |
| workout | 获取今日训练 | P0 |
| workout | 创建训练 session | P0 |
| workout | 完成训练上报 | P0 |
| growth | XP、等级、属性成长计算 | P0 |
| unity | 返回 Unity 可消费的 `unityEvent` | P0 |

验收：

- 今日训练 -> 创建 session -> 完成训练 -> 返回成长结果 能完整跑通。

### Sprint 3：皮肤、AI、商业化预留

目标：角色可换装，有 AI 教练入口，支付字段先预留。

| 模块 | 任务 | 优先级 |
|---|---|---|
| asset | 皮肤 / 装备列表 | P1 |
| asset | 用户拥有资产 | P1 |
| asset | 装备皮肤 | P1 |
| ai | AI 教练基础聊天接口 | P1 |
| payment | 订单 / 订阅表结构预留 | P1 |
| admin | 简单内容管理预留 | P2 |

验收：

- 获取资产 -> 装备皮肤 -> 返回 `CHANGE_OUTFIT` 事件。
- AI 聊天接口能基于用户档案和训练记录返回建议。

## 6. Unity Sprint

### 第 1 周：角色展示和动画跑通

| 天数 | 任务 | 交付 |
|---|---|---|
| Day 1 | 创建 Unity 项目、整理目录结构 | `AvatarHomeScene`、基础工程结构 |
| Day 2 | 导入 Humanoid 角色模型 | 场景中能看到角色 |
| Day 3 | 导入 5 个训练动画 | 深蹲、俯卧撑、平板支撑、开合跳、弓步 |
| Day 4 | 实现 `AvatarAnimationController` | 可通过按钮切换动画 |
| Day 5 | 搭建基础灯光、镜头、训练空间 | 角色展示效果达到 Demo 水平 |

验收：

- 角色能正常显示
- 至少 5 个动作可播放
- 动画切换不卡死
- 场景帧率稳定

### 第 2 周：Flutter 通信和训练反馈

| 天数 | 任务 | 交付 |
|---|---|---|
| Day 6 | 实现 `UnityBridge` 和命令路由 | 能接收 JSON 指令 |
| Day 7 | 接入 `PLAY_ANIMATION` | Flutter 可触发角色动作 |
| Day 8 | 接入 `SET_AVATAR_STATE` | 可设置等级、属性、状态 |
| Day 9 | 实现 `WORKOUT_COMPLETE` | XP、升级、属性增长反馈 |
| Day 10 | 增加升级动画和基础特效 | 训练完成后有明确成长感 |

验收：

- Flutter 能向 Unity 发指令
- Unity 能响应动作播放
- 训练完成后能播放成长反馈

### 第 3 周：换装、截图、移动端测试

| 天数 | 任务 | 交付 |
|---|---|---|
| Day 11 | 实现基础换装 / 换材质 | 至少 2-3 套皮肤 |
| Day 12 | 实现 `CHANGE_OUTFIT` 指令 | App 可切换角色皮肤 |
| Day 13 | 实现分享截图 | 输出角色分享图 |
| Day 14 | iOS / Android 嵌入测试 | 真机可跑 |
| Day 15 | 性能优化和 Demo 打磨 | 可演示版本 |

验收：

- App 内能展示 Unity 角色
- 可播放训练动作
- 可完成成长反馈
- 可换装
- 可生成分享图
- 中端手机目标 30 FPS 以上

## 8. 第一阶段不做

- 实时摄像头动作纠错
- 完整社交社区
- 好友系统
- 排行榜
- UGC 课程平台
- 复杂 3D 捏脸
- 高精度人体扫描
- 多人同屏 3D
- 大型开放训练场景

## 9. 第一阶段总体验收

### 产品验收

- 用户 5 分钟内完成首日流程
- 角色在启动后尽早出现
- 训练后有明确成长反馈
- 用户能进入角色主页继续探索

### 技术验收

- App 内能稳定展示 Unity 角色
- 至少支持 5 个训练动作
- 支持 `SET_AVATAR_STATE`
- 支持 `PLAY_ANIMATION`
- 支持 `WORKOUT_COMPLETE`
- 支持 `CHANGE_OUTFIT`
- 后端能完成注册、建档、建角、训练上报、成长计算

### 性能验收

- 中端手机角色页目标 30 FPS 以上
- 首次进入角色页加载时间可接受
- App 切后台再回来状态可恢复
